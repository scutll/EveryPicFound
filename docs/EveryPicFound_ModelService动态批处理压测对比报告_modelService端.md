### 趋势结论

1. 动态批处理在 ModelService 裸接口层面是稳定有效的，并且不是只在 `VU=25` 单点成立。
2. 文本接口收益更依赖请求并发形态，`VU=15/25` 的收益最亮眼，`VU=20/30` 稍有回落，但仍显著优于原始版本。
3. 图片接口收益最稳定，说明图片预处理与 GPU 推理的合批更容易持续吃满。
4. 从裸接口测试看，动态批处理的主要价值已经可以确定为：
   - 显著抬高图片向量化吞吐上限
   - 明显压缩文本与图片接口的尾延迟
   - 在中高并发下更有效地摊薄固定开销

## 结论

1. 动态批处理对文本、图片两个接口都带来了显著收益，且失败率没有上升。
2. 文本接口收益主要体现在吞吐翻倍和延迟减半，说明批量 tokenizer + 批量推理已经明显摊薄了单请求固定成本。
3. 图片接口收益更大，说明图片预处理与 GPU 推理的批量合并效果更明显，原始串行模式中的固定开销占比更高。
4. 多 `VU` 复测后可以进一步确认：当前动态批处理收益不是单点巧合，而是在 `VU=5/10/15/20/25/30` 的矩阵下都稳定存在。
5. 仅从 ModelService 裸接口看，动态批处理更像“稳定提升基础吞吐与压缩尾延迟”的能力；后续全链路收益大小，还取决于上游请求是否能把这些批次真正喂饱。
