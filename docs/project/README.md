# 项目级文档

本目录记录跨业务模块的当前项目事实，是产品范围、系统边界和公共契约的权威入口。

## 现有文档

建议按以下顺序阅读：

1. [EveryPicFound PRD](EveryPicFound_PRD.md)：产品目标、用户场景和功能范围。
2. [系统架构设计文档](系统架构设计文档.md)：系统组件、部署关系和核心链路。
3. [模块设计文档](模块设计文档.md)：后端模块职责、边界和协作方式。
4. [数据模型设计文档](数据模型设计文档.md)：跨模块共享或需要全局理解的数据结构。
5. [接口文档](interface_docs.md)：当前项目对外及主要内部接口。

## 收录规则

- 内容应同时影响多个模块，或作为多个模块共同遵守的项目事实。
- 单个模块的实现细节放入 [`../modules/`](../modules/)。
- 工具的通用原理和使用方式放入 [`../technologies/`](../technologies/)。
- 项目实现变化导致本目录结论失效时，必须在同一任务中同步更新。
