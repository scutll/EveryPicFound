## 收录规则

- 记录“本项目在此模块怎样实现、为什么这样实现”。
- Topic、Key、参数、消息字段、事务规则和代码入口等项目专用信息以本目录文档为准。
- 可脱离 EveryPicFound 阅读的工具架构与通用用法放入 [`../technologies/`](../technologies/)，模块文档只保留结论和链接。
- 编码切片结束时更新受影响的设计与计划；过程记录保持简短，长期可复用知识再单独提炼。
